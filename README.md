# LIT-MUN

The root repository for the LIT-MUN project. This repository is the placeholder and future home for the complete project; implementation has not started yet.

## Project

LIT-MUN is intended to become a Model United Nations (MUN) website. The project scope, technology stack, and implementation details are still to be decided.

## Repository status

The repository contains the initial frontend and backend folder structure. No application code, dependencies, or setup commands are available yet.
