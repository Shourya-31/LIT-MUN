Placeholder for the LIT-MUN website frontend. The framework and build tooling have not been selected yet.

- `src/components/` — reusable interface components
- `src/pages/` — page-level views, grouped by route:
  - `home/`
  - `about/`
  - `committees/`
  - `schedule/`
  - `resources/`
  - `registration/`
  - `sign-in/`
  - `sign-up/`
  - `dashboard/`
  - `faq/`
  - `contact/`
- `src/assets/` — images, icons, and other static assets
- `src/styles/` — shared styles
- `tests/` — frontend tests
